## Tailwind CSS, Vitest, React Testing Library, ESLint, Prettier

# Currency Converter

## Requirements:

Node.js (22) + NPM

## Getting started

- nvm use 22
- npm install
- Configure API key in .env `CURRENCY_BEACON_API_KEY=YOUR_API_KEY`
- npm run dev

## Available commands and checks:

- npm run test
- npm run lint
- npm run prettier
- npm run check (prettier + lint)
- npm run build
